Alur Kerja Modul Article Publish 
Validasi kelengkapan 100%, pemilihan channel tujuan (ATOM/Marketplace), eksekusi asynchronous batch publish melalui 
queue job, dan integrasi payload komprehensif ke EIGER ATOM. 
 
Syarat Mutlak Publikasi: 
 1. Nilai 'completeness_percentages' pada artikel generic dan seluruh varian warna HARUS bernilai 100. 
 2. Status artikel TIDAK BOLEH Draft ('is_draft = 0' dan status SAP Generic 'complete'). 
 3. Setiap varian wajib memiliki pemetaan warna, ukuran, dan aset visual utama. 
 
PUBLISH PROCESS (PimArticlesPublishController)                                                  
- Filter ketat di GET /publish-list: Hanya menampilkan artikel dengan completeness = 100%      
- User memilih artikel & channel (GET /channel-list -> 'ATOM')                                
- POST /publish (Batch Trigger):                                                                
        a. DB Transaction & Pessimistic Lock pada baris enrichment                                  
         b. Insert pim_article_enrichment_publish (Status: 'On Progress')                           
         c. Insert pim_article_enrichment_publish_variant (Status: 'In Progress')                   
         d. Dispatch asynchronous PimPublishArticleJob ke Queue                                    
     - Worker Background Execution:                                                                 
        * AtomChannel -> PimArticlePublishBackJob::dispatchSync                                    
        * Transform data pengayaan, media, rating, varian -> Kirim ke EIGER ATOM API                
        * Update status final: 'Published' / 'Failed' & tulis log ke pim_transaction_publish_log
